API Authentication

All API requests (except public templates) require authentication. Django REST Framework verifies permissions on every request.

Quick testing in Postman: Use Basic Authentication inside Postman with your normal web portal username and password. This will bypass CSRF token checks and log you in automatically for that API transaction.
Base URL
{{ base_url }}
All API paths listed below should be appended to this Base URL.
9-Level RBAC Permissions Matrix
  • GET (Read Scoping): Level 9 (Personal), Levels 6 & 8 (Own Store), Level 7 (Regional), Levels 1–5 (Global).
  • POST (Create): Sales, Invoices, and Inventory open to all authenticated employees. System Master data requires Admin.
  • PUT (Update): Inventory updates restricted to Managers (Levels 1–8). Sales, Invoice & Store edits restricted to Senior Management (Levels 1–4). Level 9 cannot edit existing sales/invoices.
  • DELETE (Remove): Restricted strictly to Senior Management (Levels 1–4).

Reports & Analytics APIs

GET-only endpoints that output aggregated stats, charts, and report matrices.

GET /api/employee_sales/
Employee Sales Report

Fetches a listing of employees with their total sales count and total revenue generated. Supports search and pagination.

Success Response Structure (200 OK)
{
  "status": true,
  "total": 1,
  "page": 1,
  "page_size": 25,
  "data": [
    {
      "employee_id": 1,
      "employee_name": "Sebastian Vettel",
      "sales_count": 12,
      "total_sales_value": 450000.00
    }
  ]
}

Store Sales Report

Fetches total sales count and total revenue grouped by retail store. Supports search and pagination.

  "total": 1,
  "page": 1,
  "page_size": 25,
  "data": [
    {
      "store_id": 1,
      "store_name": "Berlin Center",
      "sales_count": 48,

GET /api/store_vehicle_sales/
Store Vehicle Sales Report

Fetches reports on vehicle sales performance per store, grouped by vehicle models and makes.

GET /api/budget-vs-sales/

Invoices Management API

CRUD endpoints for Invoice instances. Handles billing details linked to sales records.

GET /api/invoices/
List & Search Invoices

Fetches invoices. Supports query filters like payment_status and payment_method.

Query ParameterTypeDescription
pageIntegerPage number (default: 1)
page_sizeIntegerItems per page (default: 25)
searchStringSearch query matching customer, invoice ID, or stores
payment_statusStringFilter by status: e.g. Paid, Unpaid, Overdue
POST /api/invoices/
Create Invoice (Staff Only)

Generates a billing invoice for an existing sale transaction.

JSON Request Body
{
  "sell_id": 1,
  "invoice_date": "2026-07-15",
  "due_date": "2026-08-15",
  "payment_status": "Paid",
  "payment_method": "Cash",
  "discount_amount": 150.00,
  "notes": "Fast payment discount applied."
}
PUT /api/invoices/<int:pk>/
Update Invoice (Staff Only)

Modifies fields of an existing invoice by primary key.

E-Commerce Public & Marketplace APIs

Public search, catalog filters, shopping cart, test drive booking, customer orders & messaging endpoints.

GET /api/catalog/
Catalog Search & Filter

Query vehicle inventory with pagination & dynamic filters (brand, body, price, condition, state, miles, trim).

Query Parameters
  • q: Model keyword search string
  • brand / make: Make name filter (e.g. BMW)
  • body: Body type (e.g. Sedan, SUV, Truck)
  • condition: Vehicle condition (new, used, all)
  • min_price & max_price: Price range filter
  • count_only=1: Returns integer count of matching inventory vehicles
GET /api/bodies/
Vehicle Body Types

Returns distinct vehicle body categories with live inventory counts and SVG icons.

GET /api/conditions/
Vehicle Condition Tabs

Returns vehicle condition categories (All Car, New Car, Used Car) with live inventory counts.

GET /api/models/
Distinct Models by Brand

Returns distinct vehicle model names filtered by brand parameter.

GET /api/trims/
Distinct Trims by Brand & Model

Returns distinct trim specifications for given brand and model parameters.

Terms of Service & API Acceptable Use

Welcome to the Automobile Marketplace & Management Platform. By accessing our web application, APIs, or services, you agree to comply with the following terms:

  • API Access & Authentication: API endpoints require valid user authentication. Unauthenticated requests to restricted resources will return 401 Unauthorized or 403 Forbidden.
  • Rate Limits & Usage: Automated API scraping or rapid requests without caching are prohibited. Excessive requests may trigger temporary IP rate limits.
  • Vehicle Reservation & Pricing: Prices, MMR valuations, and vehicle statuses are dynamically updated. Vehicle reservations via cart or test-drive bookings are subject to store verification.
  • User Responsibilities: Users are responsible for maintaining the confidentiality of their credentials. Any actions performed under an account are the responsibility of the account owner.

Privacy & Data Protection Policy

We are committed to protecting your privacy and personal data. This policy outlines how we handle customer and employee information:

  • Data Collection: We collect personal information provided during account registration, profile updates, test-drive bookings, and order submissions (e.g., name, email, address, phone number).
  • Data Security & Password Hashing: All password credentials are stored using PBKDF2 with SHA-256 algorithm. Raw passwords are never stored or logged in plain text.
  • Data Sharing: Customer data is shared exclusively with the designated dealership store and assigned sales representative for processing inquiries, test drives, and vehicle orders. We do not sell user data to third parties.
  • Access & Correction: Users can view, edit, or update their personal details at any time via the /profile/ endpoint or profile settings.

Cookie & LocalStorage Policy

Our platform uses cookies and browser local storage to provide a seamless browsing experience:

  • Essential Cookies:
    • sessionid: Maintains your logged-in user session securely across pages.
    • csrftoken: Protects against Cross-Site Request Forgery (CSRF) on form and API submissions.
  • Browser LocalStorage:
    • compare_inventory_ids: Stores selected vehicle IDs locally on your browser to support side-by-side vehicle comparisons across pages without requiring database writes.
  • Cookie Management: You can manage or disable cookies via your browser settings. Note that disabling essential cookies will prevent logging in to customer or management portals.
